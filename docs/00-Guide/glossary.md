# 常用术语速查

| 英文 | 中文 | 一句话解释 |
|---|---|---|
| Monocular | 单目 | 只有一个相机视角的观测 |
| Stereo Pair | 双目对 | 同一时刻对应的左右视图 |
| Baseline | 相机基线 | 左右相机光心距离 |
| Depth | 深度 | 场景点与相机之间的位置量，需说明坐标约定 |
| Disparity | 视差 | 同一场景点在两个整列图像上的水平坐标差 |
| Rectification | 立体校正 | 让极线大致水平，便于水平对应 |
| Occlusion | 遮挡 | 部分场景点在一个视角不可见 |
| Disocclusion | 新显露区域 | 目标视角中新出现、源视角看不见的区域 |
| Forward Splatting | 前向散射投影 | 源像素将贡献分发到目标位置 |
| Backward Warping | 反向采样 | 目标像素反查源图像取样 |
| Z-buffer | 深度缓冲 | 多源贡献相撞时优先选较近表面 |
| Inpainting | 内容补全 | 用上下文推断缺失或失真区域 |
| Optical Flow | 光流 | 相邻帧像素表观位移 |
| Temporal Consistency | 时序一致性 | 同一内容随时间变化自然、不闪烁 |
| LPIPS | 感知距离 | 利用特征度量感知外观差异，通常越低越好 |

术语在不同论文中可能存在特定定义；优先以原论文及代码中的坐标系与符号为准。
