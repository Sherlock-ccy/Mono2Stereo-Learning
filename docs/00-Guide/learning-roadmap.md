# 学习地图：从概念到可复现实验

## 路线总览

- [ ] **阶段 A：基本几何**：理解相机内参、基线、深度与视差；能推导 $d=fB/Z$。
- [ ] **阶段 B：像素变换**：理解 backward warp 与 forward splatting 的差异；能解释空洞和多源贡献。
- [ ] **阶段 C：视频深度**：理解逐帧估计与联合时序估计的权衡。
- [ ] **阶段 D：生成与修复**：理解 Mask、时空补全和视频扩散条件。
- [ ] **阶段 E：对照论文**：按“输入—输出—训练数据—损失—指标”比较不同方法。
- [ ] **阶段 F：读源码与部署**：能画出张量数据流、记录安装环境并生成最小结果。
- [ ] **阶段 G：评价与研究**：设计控制变量、消融实验与失败案例分析。

## 一次只做一个小闭环

例：学完[前向投影](../02-Core-Technologies/forward-splatting)，写一个 $8\times8$ 的小图移动脚本；将空洞、冲突、融合结果画成三幅图；最后对照论文中的实现。先理解机制，再追求工程运行速度。

## 如何记笔记

采用 `核心问题 → 一句话解释 → 示意图 → 公式/伪代码 → 易错点 → 引用 → 待验证问题` 的顺序。**学习所得和自己提出的猜想要分开标注。**
