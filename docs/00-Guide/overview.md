# 领域概览：什么是单目转双目立体视频

## 1. 任务定义

给定连续单目视频 $L_1,\ldots,L_T$，希望产生与其对应的右眼视频 $R_1,\ldots,R_T$，组成可以双目观看的立体视频。通常左眼视频保持输入不变，右眼内容需要满足**双目视差合理、内容忠实、时间连续**。

> [!IMPORTANT] 立体视频不是把同一段视频复制两份。若左右图完全相同，双目视差几乎为零，无法表现原场景的立体层次。

## 2. 主流技术路线

![技术路线](/images/route-map.svg)

| 路线 | 典型流程 | 优势 | 主要风险 |
|---|---|---|---|
| 深度 → 投影 → 补全 | 估计 $D$，重投影右眼，补全新暴露区域 | 几何直观、易定位问题 | 深度误差、边界空洞和混合 |
| 几何引导的生成 | 深度/视差参与生成控制 | 易结合生成先验与几何约束 | 生成内容是否严格遵守几何 |
| 直接右眼生成 | 模型学习从左眼到右眼的条件映射 | 可能减少显式几何管线 | 几何一致性与数据依赖 |

上述只是教学分类；有些论文同时采用多种策略。[StereoCrafter](../03-Papers/stereocrafter)属于前一类；[M2SVid](../03-Papers/m2svid)在投影后进行前馈修复；[DreamStereo](../03-Papers/dreamstereo)主要研究高效立体遮挡补全，而不是独立完整的视频转换流水线。

## 3. 至少要同时看四种质量

1. **外观保真**：右眼图像是否保持左眼物体身份、纹理和结构。
2. **双目几何**：生成的左右对应关系和视差是否合理。
3. **时序稳定**：连续帧的细节和视差是否出现不合理抖动。
4. **计算代价**：分辨率、帧数、显存、耗时、模型规模。

入门练习：将任意一帧左右图并排显示，标注 3 个可匹配的点，观察它们的水平位移是否相同。
