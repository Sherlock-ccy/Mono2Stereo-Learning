# 深度、逆深度与视差的区别

## 三个概念不要混

**深度** $Z$：摄像机坐标下的距离量；**逆深度** $1/Z$：近物体值大；**视差** $d$：整列双目对应的水平像素偏移。理想情形下 $d=fB/Z$。

| 量 | 常见单位 | 含义 | 注意 |
|---|---|---|---|
| 真实深度 $Z$ | 米 | 几何距离 | 要明确相机坐标和标定 |
| 逆深度 $1/Z$ | 1/米 | 近大远小 | 对远处变化更敏感 |
| 双目视差 $d$ | 像素 | 左右位置差 | 与焦距、基线相关 |
| 相对深度 | 不固定 | 排序和相对结构 | 未必可直接求真实视差 |

## 网络预测深度后怎么变成视差？

若网络输出的是没有统一尺度的相对深度，一种工程做法是归一化后乘目标最大视差，得到用于虚拟双目生成的**艺术化或相对视差**。这不等于恢复真实世界的相机基线。

```python
# 示例：仅用于说明归一化，不是某论文固定公式
scaled = (inv_depth - inv_depth.min()) / (inv_depth.max() - inv_depth.min() + 1e-6)
disp = scaled * max_disp_px
```

## 常见问题

1. **逐帧归一化**可能导致同一物体的视差随时间跳动。
2. **薄物体/反射/透明区域**的深度预测常不稳定。
3. 使用不同数据集比较，必须统一虚拟基线、视差强度、分辨率和左右方向。
