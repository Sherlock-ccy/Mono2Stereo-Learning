# 扩散模型与视频补全入门

## 一句话

扩散生成模型通过学习逐步去噪的过程，从噪声中产生符合条件的内容。视频扩散模型还要同时处理多个帧之间的关系。

## 理解五个对象

| 对象 | 做什么 |
|---|---|
| VAE | 压缩/还原图像到潜在空间 |
| UNet/DiT | 在条件信息辅助下预测噪声、速度或其它训练目标 |
| Scheduler | 规定去噪时间步与采样更新 |
| Conditioning | 输入视频、视角、Mask、深度等条件 |
| Temporal attention | 让跨帧内容交互，减少跳变 |

## 为什么重投影后还需要扩散？

投影能搬运已有像素，但不能恢复原视角看不到的背景。生成模型可以从空间语义和邻近时间帧推断缺失内容，同时也可能引入不必要的新纹理。

## 学习顺序

先看一次推理的**输入、Mask、latent、输出**，再研究采样步数、训练损失和注意力结构。阅读具体代码时不要假设每篇论文都用相同的网络结构或条件拼接方式。
