# 单目立体视频的主要生成路线

| 路线 | 核心思路 | 代表研究（用于学习定位） |
|---|---|---|
| 显式深度/视差与修复 | 几何先提供大部分正确像素，生成负责新显露区域 | StereoCrafter、M2SVid |
| 自监督/几何引导 | 利用投影或自合成数据提高几何与时间控制 | SpatialDreamer |
| 直接生成目标视角 | 生成模型学习左右视角之间的映射 | StereoWorld、Elastic3D 等 |
| 高效立体修复模块 | 专注更快、更可靠地完成投影后的空洞恢复 | DreamStereo |

这些分类并不互斥。比如有的方法虽然使用生成模型，但仍然接收显式投影右眼作为条件。

研究时建议统一比较：输入条件、是否需要深度、是否明确重投影、是否仅研究 inpainting、是否需要重训练、时间窗和推理成本。**不要将只完成修复的模块与完整端到端单目视频转换系统直接当成同类 FPS 基线。**
