# 几何一致性与左右眼对应

## 什么叫几何一致？

左右图中的同一个三维点应当满足相机对应关系。在已校正的平行双目条件下，对应位置大致沿同一行，视差是水平差 $d=x_L-x_R$。

## 三种基本检查

- **重投影误差**：用估计视差将一只眼映射到另一只眼，比较可见区域颜色。
- **左右一致性**：左右估计视差是否互为对应（注意遮挡像素没有双向对应）。
- **边界一致性**：物体边界的视差突变是否与颜色/语义边缘合理匹配。

## 不宜混用的指标

PSNR、SSIM、LPIPS侧重外观；它们不能单独证明正确的立体深度。视频更要补充视差、时间与遮挡评价。

## 方法设想提示

对于已覆盖但不可靠区域，可以联合考察深度冲突和映射局部变形，但必须排除“正确前景覆盖”的正常情况，避免误删有效纹理。
