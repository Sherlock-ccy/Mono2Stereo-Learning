# 核心技术导航

核心技术围绕整个单目转立体视频任务展开，而不是围绕特定代码仓库。推荐阅读：

1. [视频深度](./video-depth) —— 获得几何信息。
2. [Forward Splatting](./forward-splatting) —— 用已有像素合成右眼初稿。
3. [遮挡与 Mask](./occlusion-mask) —— 定位无效、缺失和高风险区域。
4. [视频补全](./video-inpainting) —— 恢复新显露背景。
5. [时序一致性](./temporal-consistency)与[几何一致性](./geometric-consistency) —— 评估可观看性。
6. [直接生成与混合式方法](./generation-routes) —— 理解不同模型路线。
