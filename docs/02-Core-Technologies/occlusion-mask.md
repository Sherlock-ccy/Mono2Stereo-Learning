# 遮挡、Disocclusion 与 Mask 的语义

## 三种容易混淆的像素

- **没有覆盖的空洞**：源视角中缺少目标视角的新显露内容。
- **被覆盖但错误的像素**：有源像素投影到此处，但深度、遮挡关系或融合颜色可能不正确。
- **可靠覆盖的像素**：已有合适的源内容，不应随意让生成网络重绘。

## 最基础的覆盖 Mask

若前向投影对全 1 图进行相同映射，得到覆盖图 $A(x)$，则可以用 $M_0(x)=\mathbf1[A(x)\approx0]$ 判断无覆盖区域。实践中可能使用连续权重、阈值与形态学处理；记得分清 **1 表示需要补全** 还是 **1 表示有效**。

## 为什么 Mask 不能无限扩大？

扩大 Mask 会把正确内容也交给生成模型重建：可能修复边界，也可能破坏纹理、身份和时序稳定。应在**相同新增 Mask 面积**下与普通膨胀方法比较，避免把面积增加误当成创新收益。

## 可研究的风险信息

贡献数量、深度分歧、主贡献权重、视差梯度和投影映射导数。它们是否能稳定发现已覆盖错误区域，属于需要数据验证的假设，并非已有实验结论。
