# 时序一致性：为什么单帧好看仍然可能失败

## 三类时间问题

1. **纹理闪烁**：同一背景在相邻帧变化。
2. **深度/视差跳动**：左右眼的立体层次忽强忽弱。
3. **遮挡边界抖动**：Mask 每帧不稳定，引起修复区域边界跳动。

## 一种分析方式

利用光流 $F_{t\to t+1}$ 对右眼视频做时序对齐。仅在可靠可见区域统计误差：

$$\mathrm{TWE}=\frac{1}{|\Omega|}\sum_{x\in\Omega}|R_t(x)-\mathcal W(R_{t+1},F)(x)|.$$

TWE 是常见的评价思想之一，具体定义、运动方向、归一化方式必须在实验中注明。

## 推荐的可视化

- 取固定像素行或物体边缘，将连续帧堆叠成时间切片图。
- 对跟踪的背景点，绘制视差随时间的曲线。
- 显示 Mask 随时间变化的热图。

要小心：真实光照变化、相机运动和遮挡本身会造成帧差，并不是所有变化都是生成模型的错误。
