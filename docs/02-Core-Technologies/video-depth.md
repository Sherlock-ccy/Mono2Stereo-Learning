# 视频深度估计：准确与稳定如何兼得

## 任务

输入视频 $I_{1:T}$，输出同长度深度序列 $D_{1:T}$。除了单帧深度精度，还必须关注**同一物体在连续帧的深度变化是否合理**。

## 两种常见思路

**逐帧图像模型**：例如 Depth Anything V2，使用方便，细节较好，但独立预测可能产生时序闪烁。**视频专用模型**：例如 DepthCrafter、Video Depth Anything，利用跨帧信息建模时间关联。

| 方法 | 主要思路 | 需要关注 |
|---|---|---|
| Depth Anything V2 | 强图像深度基础模型 | 连续帧稳定性与标尺 |
| DepthCrafter | 视频扩散生成一致深度 | 推理成本、窗口拼接 |
| Video Depth Anything | 轻量时空头、长视频推理 | 输入分辨率、动态场景 |

## 视频深度常见失败

- 相对尺度随时间漂移，使固定物体发生“呼吸式”视差变化。
- 遮挡边界过度平滑，导致投影中的前后景混色。
- 玻璃、反射和细线结构预测不稳定。

## 实验建议

固定输入视频与虚拟视差上限，比较不同深度模型对投影结果的影响；单独保存深度与 Mask，避免混入补全网络的不确定性。
