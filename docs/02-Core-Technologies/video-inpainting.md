# 视频修复：新显露背景从哪里来

## 任务

对投影产生的空洞，利用同帧可见区域、输入左眼、邻近帧或生成先验，补足目标右眼视频。视频修复与普通图像修复的关键差别是跨帧关系。

## 典型路径

1. 利用**光流或特征匹配**，把其他时间帧中真实出现过的背景传播过来。
2. 对所有时间帧都不可见或无法可靠匹配的区域，使用生成先验。
3. 使用跨帧注意力或运动约束，让纹理随时间稳定。

## 模型比较

- [ProPainter](../03-Papers/propainter)：一般视频修复，强调时空传播与高效 Transformer。
- [M2SVid](../03-Papers/m2svid)：专门针对立体视频投影后的补全与细节修正。
- [DreamStereo](../03-Papers/dreamstereo)：关注高清立体视频的快速稀疏修复。

## 常见错误

修复区域边界不连续、远距离帧引入错误纹理、物体运动导致粘连。评估时需同时关注修复区域质量和原本正确内容的保留率。
