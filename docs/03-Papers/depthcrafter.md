# DepthCrafter：长视频一致深度

**论文**：[DepthCrafter (CVPR 2025)](https://arxiv.org/abs/2409.02095) · [项目](https://depthcrafter.github.io/)

## 研究难题

逐帧深度估计会出现时序闪烁，而视频含复杂运动、场景变化和长时间序列，不能只做静态帧估计。

## 方法概要

采用视频扩散基础模型处理视频到深度的转换，借助分阶段训练获得细节和时间稳定性，并用分段与拼接处理长视频。

## 为什么与立体视频有关？

深度 $D_t$ 决定视差 $d_t$；若 $D_t$ 随时间不合理跳动，生成右眼会产生立体层次抖动，即使单帧画质不错仍可能不适宜观看。

## 学习和复现建议

分别保存连续深度序列、归一化策略、实际推理显存和运行时间；在静止背景和运动主体上观察漂移，不要只看单帧深度图。
