# M2SVid：投影后快速补全与细节修正

**论文**：[M2SVid (3DV 2026)](https://arxiv.org/abs/2505.16565) · [项目](https://m2svid.github.io/)

## 必须明确的定位

M2SVid **不是完全绕开几何投影的直接右眼生成**。它先基于深度重投影得到右眼初稿，再对空洞和投影伪影做**前馈式补全与修正**。

## 方法特点

充分利用左眼、投影右眼以及遮挡掩码作为条件；为新显露区域设计更灵活的注意力交互，减少反复去噪带来的开销。

## 对照学习

| 问题 | StereoCrafter | M2SVid |
|---|---|---|
| 右眼初稿 | 显式投影 | 显式投影 |
| 补全策略 | 视频扩散推理 | 前馈式模型 |
| 修复输入 | 依赖实现约定 | 显式考虑左眼、投影右眼、遮挡区域 |

阅读重点：**真实纹理迁移与生成补全之间的取舍**，不要把不同硬件/分辨率的速度数字直接并列。
