# SEA-RAFT：高效光流估计

**论文**：[SEA-RAFT (ECCV 2024)](https://arxiv.org/abs/2405.14793) · [代码](https://github.com/princeton-vl/SEA-RAFT)

## 为什么要读？

光流用于时序对齐、纹理传播与视频稳定性分析，是与双目视差不同但重要的运动线索。

## 主要改进思想

在 RAFT 风格框架上优化初始流估计和迭代求精策略，使用新的损失建模不确定性，并引入训练方式改善效率与泛化。

## 在学习库里的位置

它应归类为**光流基础技术**，而不是立体视频生成 baseline。阅读时重点比较：光流误差如何影响 Warp 评价、遮挡边缘和视频修复。
