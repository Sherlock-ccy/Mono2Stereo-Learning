# ZeroStereo：从单图生成立体匹配训练数据

**论文**：ZeroStereo: Zero-shot Stereo Matching from Single Images（ICCV 2025）· [代码](https://github.com/Windsrain/ZeroStereo)

## 关键定位

它主要目标是**增强立体匹配算法的零样本泛化**，通过单图深度伪标签与右图合成构造双目训练样本。虽然包含右眼图像生成，但并非完整的长视频转换方法。

## 核心问题

如何让由单图产生的伪视差具有可用的置信度，并避免不合理视差带来过强的遮挡和前景形变？

## 与你的知识库关系

可参考其数据置信度和视差选择思想，帮助辨别“伪几何不可靠”与“需要修复”的关系。要区分论文原有机制和自己设计的算法。
