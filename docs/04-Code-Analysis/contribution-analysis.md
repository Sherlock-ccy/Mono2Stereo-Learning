# Forward Splatting 的投影贡献与错误覆盖

## 从输出倒推中间量

常见散射投影会生成**颜色加权和** $S_I(x)$ 和**权重和** $S_w(x)$：

$$\hat I(x)=\frac{S_I(x)}{S_w(x)+\epsilon}.$$

如果还要分析冲突风险，可能需要额外统计：

- 覆盖贡献的数量 $N(x)$；
- 视差的加权均值与方差 $V(x)$；
- 归一化权重的熵 $H(x)$；
- 最大贡献权重所占比例与深度顺序。

## 候选统计公式（学习实验，不是已发表新方法）

$$V(x)=\sum_i p_i(d_i-\bar d)^2,\quad H(x)=-\sum_i p_i\log(p_i+\epsilon).$$

这些统计可能帮助发现**覆盖后仍可能有错误颜色**的像素，但不能单凭冲突数量或熵判错：正常前景遮挡同样存在多源竞争。

## 实现顺序

1. 先写低分辨率 CPU/PyTorch 参考实现，并打印贡献列表。
2. 在小例子上检查结果与手工推导一致。
3. 再对比 CUDA 输出和数值误差。
4. 最后研究如何最小化额外显存与 kernel 开销。

## 公平验证

保持相同虚拟视差、相同输入和相同生成模型，分别评估“真实错误像素命中率”和“原有正确纹理的误遮挡率”。对照普通形态学扩张时，需控制新增 Mask 面积。
