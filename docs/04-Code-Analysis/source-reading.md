# 读模型代码：入口、数据流、算子与输出

## 先画数据流，再读模块

![推理数据流图](/images/pipeline.svg)

建议用这五个问题理解函数：**谁调用它？输入张量是什么？输出是什么？修改了哪个维度？与哪段论文方法对应？**

## 通用阅读顺序

1. `README`、启动脚本、`main()`：先弄清参数和运行顺序。
2. 推理入口：找视频输入、模型载入、分段和结果保存。
3. 几何部分：找深度/视差转换、warping、掩码。
4. 生成部分：找 condition、Mask、latent、解码和视频保存。
5. 底层算子：最后看 CPU/CUDA 实现，确认累积与插值细节。

## 每个模块的最小记录

```text
名称：
入口文件与函数：
输入张量 shape/dtype/device：
输出张量 shape/dtype/device：
边界条件：
对应论文小节：
最小单元测试：
```

## 不要犯的三个错误

- 把代码里的 shape 猜成固定格式。常见 `[B,T,C,H,W]` 与 `[B,C,T,H,W]` 会互换。
- 因为变量名叫 `mask` 就认定 1 表示需要修复：不同实现可能相反。
- 把 GPU 算子输出的累积图直接当成每个来源的独立贡献信息。
