# 张量形状与坐标流图解

## 五个字母

| 符号 | 含义 | 常见取值 |
|---|---|---|
| B | batch | 1、2… |
| T | 视频帧数 | 16、25、32… |
| C | 通道 | RGB=3，单通道图=1 |
| H | 高度 | 像素或潜在空间高 |
| W | 宽度 | 像素或潜在空间宽 |

## 典型变化示意

```python
# 示例：视频从帧优先改为通道优先
video = torch.randn(1, 16, 3, 256, 448)  # [B,T,C,H,W]
video = video.permute(0, 2, 1, 3, 4)       # [B,C,T,H,W]
```

读 PyTorch 代码时首先定位 `permute` / `reshape` / `stack` / `cat` / `interpolate`。对每个关键断点记录 shape、dtype、device、数值范围（如 `[0,1]` 或 `[-1,1]`）。

## 立体生成特有的张量

- $D$：深度 `[B,1,H,W]` 或视频深度 `[B,T,1,H,W]`。
- $F$：光流二维位移 `[B,H,W,2]`。
- $M$：遮挡掩码，多数情况下是单通道，但具体语义取决于网络。
- latent：分辨率和通道由 VAE 决定，不可直接假定等于 RGB 形状。

建议为每个模型建立一份单独的 shape 表，不把这里的教学示例当成官方实现规范。
