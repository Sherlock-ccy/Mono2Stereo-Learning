# 一次复现实验应该记录哪些信息

复制下方模板，保存为每次实验单独的笔记：

```markdown
# 实验名称 / 日期
- 仓库及 commit：
- 系统、GPU、驱动、CUDA、PyTorch：
- 数据来源与许可：
- 输入视频：分辨率 / FPS / 帧数：
- 模型权重及版本：
- 运行命令：
- 关键参数：视差上限、窗口、推理步数、随机种子：
- 峰值显存 / 总耗时 / 计算范围：
- 生成结果（小型示例图）：
- 指标计算协议：
- 发现的问题：
- 下一步：
```

同一方法的多次实验应使用一致的输入样本、预处理和评价协议，避免把不同输入分辨率或不同 baseline 误当作公平对比。
