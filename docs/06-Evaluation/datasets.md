# 单目立体视频研究常用数据集

| 数据集 | 类型 | 主要价值 | 使用注意 |
|---|---|---|---|
| MPI Sintel Stereo | 合成双目视频 | 遮挡、深度/视差、复杂运动 | 明确 split 与渲染设置 |
| Spring | 高品质合成场景与光流/双目数据 | 高分辨率、运动与几何 | 样本数量、分辨率及许可 |
| KITTI Raw | 真实道路双目序列 | 真实相机内容和几何 | 只覆盖道路域、需校准与同步 |
| Stereo4D | 大规模互联网双目/VR180 衍生数据 | 真实动态 3D 与运动 | 鱼眼投影和相机标定不可忽略 |

## 数据不是越多越好

重要的是保证每个方法在同一视角目标、分辨率、帧率、输入时长和数据预处理下比较。真实 VR180 视频不可直接当作标准平行双目图像逐像素比较；必须处理相机模型与目标视图定义。

## 使用数据的三件事

1. 记录下载地址和授权条款；不上传大型原始数据。
2. 用独立开发集调参，测试集仅用于最终评估。
3. 保存筛选标准，避免只挑视觉效果好的样本。

参考：[Sintel](https://sintel.is.tue.mpg.de/) · [Spring](https://spring-benchmark.org/) · [Stereo4D](https://stereo4d.github.io/)。
