# 公平实验协议：从数据到指标的控制变量

## 一张实验协议表

| 项目 | 必须固定或披露 |
|---|---|
| 数据 | 数据集版本、划分、样本选择、授权 |
| 输入 | 分辨率、FPS、帧数、裁剪、压缩格式 |
| 双目 | 左右方向、虚拟基线/最大视差、相机模型、校正方式 |
| 模型 | 权重、Git commit、随机种子、精度模式 |
| 推理 | 扩散步数、切块、时间窗口、后处理 |
| 资源 | GPU 型号、显存、批大小、计时范围 |
| 评价 | 真值与生成图的对齐、遮挡 mask、指标实现 |

## 特别提醒

- 完整立体生成系统与仅 inpainting 模块，**不可直接拿 FPS 做同类排名**。
- 深度强度不同会改变新显露区域数量，从而影响补全难度。
- 自动选择最优测试样本会带来偏差；报告失败案例和平均/分布结果。
- 改进 Mask 时需要排除“只是修复更多区域”的替代解释，设计**等面积 Mask 对照**。
