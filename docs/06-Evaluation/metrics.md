# 质量指标：PSNR、SSIM、LPIPS、时序与视差

## 画质

- **PSNR↑**：基于像素均方误差，需要严格对齐目标图、范围和色彩空间。
- **SSIM↑**：比较局部结构与亮度/对比度，受窗口和实现影响。
- **LPIPS↓**：深度特征的感知差异，受网络权重、预处理和实现影响。

## 立体

- **视差误差**：若有对应视差真值，可以统计 EPE、bad-pixel 等。
- **左右循环一致性**：使用左右视差前后重映射，在可靠的非遮挡区域计算。
- **视觉舒适性**：视差强度、连续性及显示条件，不能单纯从 PSNR 推出。

## 时间

- **TWE↓**：光流对齐后的残差；需排除遮挡和不可靠光流。
- **视差时序平滑**：对跟踪一致位置统计不合理突变。
- **主观视频评价**：用户研究需明确设备、观看距离、流程、样本量。

## 对 Mask 研究更有用的额外指标

新增 Mask 面积、真实错误像素召回率、误遮挡有效像素比例，以及等面积比较下的边界 PSNR/LPIPS。

**没有真实左右成对数据时，PSNR/SSIM/LPIPS 对右眼真值的比较不可凭空计算。**
