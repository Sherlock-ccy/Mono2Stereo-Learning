# 方法比较：先对齐任务，再比较结果

| 方法 | 研究任务 | 深度/投影的角色 | 容易误解 |
|---|---|---|---|
| StereoCrafter | 完整单目转立体视频 | 深度重投影后视频补全 | 并非纯直接生成 |
| M2SVid | 完整转换框架中的修复/细化 | 投影后前馈式补全 | 并非无投影直接生成 |
| DreamStereo | 立体视频修复 | 优化投影与补全效率 | 主要是 inpainting |
| Softmax Splatting | 视频插帧中的前向投影 | 可微竞争加权 | 不是双目视频完整 baseline |
| DepthCrafter | 视频深度估计 | 上游深度 | 不是右眼视频生成器 |
| ProPainter | 通用视频修复 | 时空传播 | 不是双目转换系统 |
| ZeroStereo | 数据合成与立体匹配 | 伪视差生成训练对 | 主要评价目标不是立体视频 |

比较时先确定你究竟在比：**完整系统质量、深度精度、投影质量、补全质量、还是运行效率**。分开建表比混在一张总排名中更可信。
