# 如何设计对照实验与消融

## 研究问题：Mask 改进真的有效吗？

建议用同一深度结果、同一视差上限、同一视频补全网络，比较：

| 组别 | 内容 | 目的 |
|---|---|---|
| M0 | 原始遮挡 Mask | 基线 |
| M1 | 普通形态学膨胀 | 排除“扩大 Mask 就会更好” |
| M2 | 仅几何边界风险 | 验证边界信息 |
| M3 | 仅投影冲突风险 | 验证贡献统计 |
| M4 | 联合风险 | 检验互补性 |

## 必做三类实验

1. **投影层评价**：在有真值的可见区域测量错误像素检测能力。
2. **补全层评价**：保持补全网络冻结、相同随机种子、相同输入与参数。
3. **等面积对照**：所有方法新增相同数量像素进入 Mask，比较收益。

## 消融的正确使用

去掉某个特征后如果结果变化很小，不能为了写论文而强行认定其必要。记录无效或负面结果，同样能帮助缩小真正的研究问题。

## 统计提醒

测多个视频、多场景、多视差强度。展示均值、波动和失败案例。真实右眼参考图像本身可能存在颜色变化与对齐误差，评价规则必须明确。
