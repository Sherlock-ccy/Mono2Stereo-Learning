# 失败案例应该怎么保存

## 推荐每个案例记录六件事

- 输入视频和数据来源，是否允许公开；
- 具体帧号与场景（薄物体、玻璃、运动主体、遮挡边界等）；
- 深度、Warped View、Mask、最终右眼五联对照；
- 观察到的现象与**可能原因**（先不要写成定论）；
- 能区分原因的实验：替换深度？固定 Mask？增大最大视差？
- 改进是否真的有效，有无引入副作用。

## 典型失败分类

`DepthError` / `WarpHole` / `OcclusionMix` / `TemporalFlicker` / `TextureHallucination` / `DisparityJump`。

当某种现象无法判断由深度还是补全导致时，先只看投影中间结果；**不要直接改生成网络**。
